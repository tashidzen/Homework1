# Добро пожаловать на демо-проект сайта мини-игр.

Сайт предназначен для предоставления пользователю легкого, быстрого и доступного способа развлечения и короткого отдыха без необходимости скачивания и установки программ.

Сайт состоит из 3-х блоков: 
1) "Добро пожаловать на мой сайт мини-игр";
2) "Об играх";
3) "Мини-игры".

Между блоками реализован плавный переход. А также проведена адаптация под планшетные и мобильные устройства. Версия для смартфонов и планшетов компактна и сфокусирована на главном — мини-играх, поэтому количество блоков сокращается до 2-х: "Добро пожаловать на мой сайт мини-игр" и "Мини-игры".

Разработано 6 мини-игр: 
1) "Угадай число";
2) "Простая арифметика";
3) "Переверни текст";
4) "Камень, ножницы, бумага";
5) "Простая викторина";
6) "Генератор случайных цветов". 

## Технологии
В проекте использованы технологии: JavaScript, HTML, CSS (SASS), БЭМ, Git.
